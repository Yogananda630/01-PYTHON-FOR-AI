# 🐍 Python Data Types

Python provides built-in data types for storing and working with different kinds of values.

## 🎯 Learning Objectives

- Understand Python's built-in data types
- Identify the type of a value using `type()`
- Understand mutable and immutable collections
- Work with collections used in AI/data applications
- Choose appropriate data structures for different tasks

## 📚 Main Data Types

| Data Type | Example | Use |
|---|---|---|
| `int` | `21` | Whole numbers |
| `float` | `95.5` | Decimal values |
| `str` | `"Python"` | Text |
| `bool` | `True` | Logical values |
| `list` | `[1, 2, 3]` | Ordered, mutable collection |
| `tuple` | `(1, 2, 3)` | Ordered, immutable collection |
| `set` | `{1, 2, 3}` | Unique values |
| `dict` | `{"name": "AI"}` | Key-value data |
| `NoneType` | `None` | Absence of a value |
